## Case-study note

The first full Monday showed where an agent team stalls: every role spent its first run building infrastructure, and then stopped at the same few doors only a human can open (credentials, production migrations, environment settings). Agents can move fast inside the repo, but the human approvals become the critical path. Batching those approvals into one brief, each with a recommendation, is how the team keeps that path short.
